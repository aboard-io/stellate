00 · HOW TO READ A PAGE

Four reading laws

Voices count from 1

voice 1 is the kernel's v === 0 — the lead, usually "as written". voices 2.. is the closure's else-branch. Parts (lead, pads) address the cast; they carry the pipes.

S is entry-relative

Both call sites pass one time index, s = bar − entry(v) — sections since this voice entered. For staggered entries (fugue's entry: v => v) each voice's in odd is phase-shifted. The songbook adopts that meaning; the grammar must too (gap 09).

kernel.js:1393 · :629

Two colors of trouble

red wavy = the grammar has no way to say it at all. amber wavy = grammatical, but the value falls outside the OPKEYS alphabet the mock compiles to (e.g. rotate 8). Both are indexed in The Gaps.

+ appends, · chains

Ops apply left to right, exactly word()'s reduce. A bare + appends to the voice's previous rule — the spelling of the closures' ...(s % 2 ? [op] : []) spread, split under in odd.

02 · THE GAPS

Fourteen things the grammar cannot say

Design feedback, not shame: the catalog is the older text, and where the language cannot reach it, the language is what moves. Each item names the construct, the shipped witnesses, and — where it is obvious — the smallest extension that would cover it. Nothing here is fudged into a lookalike line above; it is red-underlined there and reported here.

  1. The skank has no verb. offbeats(n) genres.js:322 writes an ABSOLUTE off-beat grid over the gate vector, discarding the phrase's own rhythm — not composable from rotate/thin/fill and not in OPKEYS. Six genres use it: reggae:1909, ska:2001, dub:1945, merseybeat:3516, psychpop:3561, riff:5498. a verb offbeats n (or skank n) mapped one-to-one to the shipped operator.
  2. Masks have no literal. breath(mask) genres.js:337 takes a 16-step array; the grammar's expr is scalar arithmetic only. Witnesses: bodiddley:2624, doowop:2840, ebm:4507 (a 4-step mask read cyclically — a second implicit convention), vocal:5437, backing:5472. a mask literal — breath 1001·0010·0010·1000 — with the cyclic short-mask read stated as law.
  3. Masks have no names. SUNG genres.js:346 is a named constant read from closure scope (doowop:2842, vocal:5437, backing:5472) — the only thing any catalog closure reads beyond (v, s) and the ops, by token scan of all 216 field sources. §5's proposed row declarations cover pitch series only. extend §5's declaration form: mask sung = 1111·1100·1111·0000 — material with one owner, exactly like rows.
  4. The period can be a function. The doc presents period as a data schedule, but kernel.js:1204 accepts a function of (v, s), and half the catalog's periods use it (doowop:2809, minimalism:3060). Doowop's reduces to voice + bar selectors; minimalism's does not (next item). none needed for the reducible ones — the printer rewrites them; the irreducible one is gap 05.
  5. Cycles, not processes. minimalism:3060 grows a window with s < 2 / s < 4 / s < 6 and then stops — a monotone additive process. Every selector the grammar owns (odd, even, S%n=n, every n, bar n of n) is cyclic. The genre's own comment says why it matters: "an operator is timeless and cannot know it is in bar 3." The largest structural gap in the language. a monotone selector pair — until n / after n — still counters, still deterministic, just not modular.
  6. Expressions must start with a literal, and there is no unary minus. rotate(s) (minimalism:3060) needs the artificial 1·S; transpose(-(s % 3)) (concerto:5745) — "down S%3" — cannot be written at all. let expr begin with a counter; let down negate its whole argument.
  7. No parentheses, no precedence. jamband:4299 needs (S%4)+2; the flat left-to-right chain parses 2+S%4 as ((2+S)%4) — a different song. parens in expr, or standard precedence (· % over + −).
  8. No conditional inside an argument. counterpoint:878 invert(s % 2 ? 0 : 5), electro:3313 excerpt(s % 2 ? 8 : 0, 8), and the spread-conditional append idiom ...(s % 2 ? [op] : []) in 13 genres (acid, spem, dub, concerto, classical, …). All sayable by splitting one closure into rules under in odd / in even — legal, but a rewrite. none — instead, the extraction gate must accept an n-line rendering of a 1-expression closure, and the printer must own the split.
  9. S is per-voice at the seam. The grammar promises S, B, V; both word call sites (kernel.js:629, 1393) pass one index, s = bar − entry(v) — and it is phase-shifted per voice under staggered entries, so an absolute in S%3=1 cannot reproduce fugue:432's table. The doc's own §4 fugue card overstates its translatability. define S as "sections since this voice entered" (this songbook already reads it that way), or pass absolute indices at the seam and keep both words.
  10. The catalog outruns the OPKEYS alphabet. §1 claims the parser's entire output type is OPKEYS; §6's mock errors "rotate takes 1..7". The shelf disagrees: rotate 8 in ~30 genres (blues:687, dnb:1612, boombap:1455, congorumba:6823, …), rotate 12 (:8526), rotate 3·S / 5·S (arsnova:5664); drop 1 (swing:10078) and drop 8; fill 1 (screamo:4001, industrialmetal:4451, …); transpose ±3…±12 everywhere vs trm2..trp2; invert 0/2/5 (counterpoint:878, fugue:432, baroquepop:5695, sophisti:5856) vs inv = invert(4); excerpt(8, 8); and only("gate", …) over arbitrary ops vs the fixed gat/pit keys. parameterized keys (rot(k), tr(k), inv(c), on(vec, key)) — or admit the language compiles to closures and re-state §1.
  11. Decimals and division are undefined. spread(0.5) (vocal:5437; OPKEYS tight) — the token n is never defined, expr has · + − % but no ÷, yet §3's own spread row says "÷2 narrows". spread's optional pivot (kernel.js:119) also has no word, though no catalog closure uses it. define n to admit decimals; that alone covers every witness.
  12. The cyclic wrap is implicit. vaporwave:595 computes (s·4) % 16; the §4 card spells it loop 8 from 4·S and silently leans on cyclic at() reads (kernel.js:59) to absorb the wrap. Every over-range rotate leans on the same fact. state it as a language law: all counter arithmetic is read mod pattern length.
  13. Multi-argument forms exceed the EBNF. op ::= verb [expr] [on vector] [seed name] has one expr slot; §3's own rows need two: loop n from a (excerpt), copy a to b (crossmap), harmonize sixth at .4 (a word-token gap plus a probability). And backing:5467 ships { id: "harmonize", p: 1 } with no gap at all — a spelling the grammar does not show. give the verb rule its real arity per verb, and a gap-less harmonize (default: third).
  14. Three features, zero witnesses. Honesty runs the other way too: crossmap / "copy a to b" is used by no genre (only the OPKEYS slides/stick keys exist); the echo pipe (echoCanon) is used by no genre; and no catalog period uses the OPKEYS string form (["thin3"]) the doc celebrates — beatles:1315 and garage:1551 hold raw closures. §8's extraction gate would ship three grammar features with no fixture. either seed one catalog witness each, or mark them speculative in the spec.
